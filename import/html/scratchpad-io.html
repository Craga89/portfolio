Scratchpad.io – Real-time HTML/CSS rendering

scratchpad.io is a great little web app by Sandbox Labs that renders your CSS and HTML in real time as you type, and includes localStorage persistence to stop you from accidentally F5′ing it away! Great for testing out the beginnings of a design, check it out!
