One product in 36 languages, kept in step

Customers survey their people in their own language, so the interface and the questions have to work in every language they turn on. I’ve kept the platform’s 36 interface languages in step with English, and made translating customers’ own content cache-first and selective.

# in practice
  • A changed or removed string updates every language in the same change, so no file falls behind.
  • Untranslated text shows in English rather than as a gap on screen.
  • Adding a language means adding its file; the build generates the rest.
  • Customer content is translated only when it should be, and served from a cache next to the services.
  • This site follows the same ideas on the visitor’s own device: English fills any gap, translations are cached, and names and file names are never translated. See this-site.md.
