# in practice
  • AI features are built as agents and workflows in TypeScript, so any engineer on the team can work on them.
  • The AI service has its own account, with its own permissions and its own bill, separate from the core platform.
  • Changes to the AI service are checked by its eval suite in CI before they reach customers.

# terms used

Mastra
An open-source TypeScript framework for building AI agents and workflows.
Amazon Bedrock
AWS's service for using foundation AI models through an API, inside your own AWS account.
Eval suite
Automated tests for AI behaviour: set inputs checked against expected qualities, run on every change to catch regressions.
