A test suite that kept up with the platform

I led the inception of the first automation suite, built on Cypress, and evolved it in CI over time alongside the Test Automation Engineers. As the suite grew, its performance suffered, so I led the switch to Playwright, which brought huge gains in performance and stability across the CI/CD environment.
