Nothing public but the CDN

I led the platform's move from containers on EC2 hosts behind a public load balancer to Fargate tasks that talk over ECS Service Connect, with all customer traffic entering through CloudFront and WAF. Each step shipped without a big-bang cutover.

How it evolved: hosts to patch → no hosts at all
  1. started as: ECS on EC2 hosts
  2. then: capacity autoscaling
  3. then: awsvpc networking
  4. then: Fargate rollout
  5. today: Fargate + Service Connect
# in practice
  • No servers to patch: every service runs on Fargate.
  • The attack surface is one CDN. WAF moved to blocking only after a 14-day shadow run showed no legitimate traffic would be stopped.
  • Each service receives only the events it handles, using subscription filters generated from its code at build time.
  • Dev environments share one networking stack and one database cluster, so a new environment is cheap to stand up.

# terms used

ECS Service Connect
An AWS feature that lets services in a container cluster find and call each other, with traffic metrics built in.
