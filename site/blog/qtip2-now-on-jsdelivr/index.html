qTip2 - Now on jsDelivr

  • Plugins
  • JavaScript
  • qTip2

First published on my old blog (blog.craigsworks.com) in December 2013, and kept as it was written. Some code and links are out of date.

qTip2 is now officially available through the jsDelivr CDN, and is the CDN of choice for the library starting from today's update! jsDelivr has better performance and availabilty than current the CDNJS service, so it's a welcome addition to the libraries availablity.

You can grab the latest stable releases (and older releases too!) from the project page and official download page.

Note: qTip2 will still be available as usual from the CDNJS CloudFlare service, but pull request responses are a little slower than jsDelivr, so new releases may not be immediately available.
